PinkBook API

Este sitio publica únicamente el backend (funciones de Netlify) de la aplicación PinkBook. El frontend se publica por separado.

Primero ejecute /.netlify/functions/dbCreate para inicializar la base de datos de Redis Cloud.

Servicios

FunciónMétodoDescripción
dbCreateGET/POSTInicializa libros, autores y editoriales.
bookFindAll / authorFindAll / publisherFindAllGETLista todos los registros.
bookFind/<id> / authorFind/<id> / publisherFind/<id>GETConsulta un registro.
bookInsert / authorInsert / publisherInsertPOSTEncola un alta en la lista bookstore.
bookUpdate/<id> / authorUpdate/<id> / publisherUpdate/<id>PUTEncola una modificación.
bookDelete/<id> / authorDelete/<id> / publisherDelete/<id>DELETEEncola una eliminación.
bookTasks / authorTasks / publisherTasksGET/POSTProcesan las actualizaciones pendientes de su entidad.
updatesPendingGETCantidad de actualizaciones pendientes y con error.
